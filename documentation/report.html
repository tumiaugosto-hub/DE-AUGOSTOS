1. Website Specifications

1.1 Website Name

DE AUGOSTOS INVESTMENTS

1.2 Website Objectives

The primary objective of the DE AUGOSTOS INVESTMENTS website is to promote the company's services online and provide customers with easy access to information about the services offered. The website supports the company's vision of becoming the best and most recognized automobile business specializing in German-manufactured machines by the year 2035. By establishing a strong online presence, the website serves as a digital storefront that communicates the company's expertise, professionalism, and commitment to quality.

1.3 Website Goals

  • Advertisement of new products and services – Showcase the full range of automotive services and products offered by DE AUGOSTOS INVESTMENTS.
  • Pricelist and specials – Provide transparent pricing information and highlight special offers on products and services.
  • Contact and location details – Make it easy for customers to find the business and get in touch via phone, email, or contact form.
  • Company promotions and competitions – Display current promotions, discounts, and customer competitions to drive engagement.
  • Company profile – Communicate the company's history, mission, vision, and values to build trust with potential customers.
  • Customer queries – Allow customers to send inquiries through a contact form with proper validation.
  • Tech support and downloads – Provide downloadable resources such as brochures, pricelists, software, and service documentation for customers and mechanics.

1.4 Target Audience

The business specializes in servicing German-manufactured machines (BMW, Mercedes-Benz, Audi, Volkswagen), which are widely recognized for their high quality and engineering excellence. The target audience includes:

Audience SegmentDescription
Car OwnersIndividuals who own German vehicles and require maintenance, repairs, or performance upgrades.
Individual Mechanics (Bush Mechanics)Independent mechanics who need technical support, parts, and diagnostic assistance.
Professionals & EntrepreneursAged 28–60, this group influences the market and demands high-quality service for their premium vehicles.
Performance EnthusiastsAutomotive enthusiasts interested in street performance and racing, often connected through social clubs.

1.5 Technical Abilities of Users

Users are expected to:

  • Use smartphones and laptops to access the website
  • Have basic browsing and navigation skills
  • Access the website via Google search or direct URL
  • Be comfortable filling out online forms and downloading files

1.6 Type of Website

Business Website – This is a corporate/business website designed to promote DE AUGOSTOS INVESTMENTS, provide information about services, and facilitate customer engagement through contact forms and downloadable resources.

6. Publishing & Promotion

6.1 Hosting Platform

The website is hosted on GitHub Pages, a free static website hosting service provided by GitHub. GitHub Pages allows direct deployment from a GitHub repository, making it ideal for hosting static business websites.

6.2 Deployment Process

The following Git commands were used to initialize the repository, track changes, and publish the website:

# Initialize a new Git repository
git init

# Add the remote GitHub repository
git remote add origin https://github.com/tumiaugosto-hub/DE-AUGOSTOS.git

# Stage all files for commit
git add .

# Commit the files with a descriptive message
git commit -m "Initial commit: DE AUGOSTOS INVESTMENTS business website"

# Push to the main branch
git push -u origin master

# Subsequent updates after changes
git add -A
git commit -m "Description of changes made"
git push origin master

7. Future Developments / Recommendations

While the current website is fully functional and meets the assignment requirements, there are several enhancements that could be implemented in future iterations:

7.1 E-Commerce Integration

Implement a full e-commerce system allowing customers to purchase parts and products directly through the website with a shopping cart, payment gateway (e.g., PayPal, PayFast), and order tracking functionality. This would transform the website from an informational platform into a revenue-generating online store.

7.2 Content Management System (CMS)

Integrate a CMS such as WordPress or a headless CMS (e.g., Strapi, Contentful) to allow the business owner to update content, add new products, modify pricelists, and manage promotions without needing technical skills. This would make the website more maintainable and scalable.

7.3 Appointment Booking System

Add an online booking system where customers can schedule service appointments, select the type of service required, choose preferred dates and times, and receive automated confirmations and reminders via email or SMS. This would streamline the customer experience and reduce administrative workload.

7.4 Customer Portal / Account System

Implement user registration and login functionality, allowing customers to create accounts, view service history, track vehicle maintenance schedules, download invoices, and save favourite products for future purchases.

7.5 Multi-Language Support

Add support for multiple languages (English, Setswana, etc.) to cater to a broader audience in Botswana and across the region. This would enhance accessibility and user experience for non-English speaking visitors.

7.6 Performance Optimization

Implement advanced performance optimizations including image lazy loading, WebP image format conversion, CSS/JS minification, CDN integration, and caching strategies to improve page load speeds, especially on mobile networks.

7.7 SEO & Analytics

Implement comprehensive SEO strategies (structured data, meta tags optimization, sitemap.xml, robots.txt), integrate Google Analytics for visitor tracking, and set up Google Search Console to monitor and improve search engine rankings.

7.8 Social Media Integration

Enhance social media integration with live feeds from Facebook and Instagram, social sharing buttons on promotions and products, and social login options for customer accounts to improve engagement and brand visibility.
